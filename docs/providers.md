# المزودون

المتاح في المرحلة 3: Mock وGemini وOpenAI وDeepSeek وOpenRouter وCustom
OpenAI-compatible وGoogle Translate عبر deep-translator غير الرسمي.
تفاصيل الإعداد والاختبارات والقيود في [دليل المرحلة 3](phase3.md).

`mock` يعمل دون شبكة أو مفتاح ويعيد نص الطلب نفسه
مع إعلان المحاكاة. `test_connection` لا يختبر خدمة خارجية و`list_models` يعيد `None`.
كل نتيجة تحمل معرّف الوحدة؛ لا تربط النتائج حسب ترتيبها.

أصبح `mock-demo` يمرر عينة مدمجة عبر الحماية ثم Mock ثم التحقق والاستعادة، دون
تغيير عقد المزود. تفاصيل [الحماية في المرحلة 2](phase2.md). ينظم TranslationManager
الدفعات والحماية والاستعادة والذاكرة والحفظ والاستئناف عبر العقد نفسه.

تُثبت SDK الاختيارية عبر `.[llm]` عند تشغيل الشيفرة، وتُضمّن في EXE المبني معها.
اختُبرت الموصلات باستجابات HTTP محاكية وSDK مثبتة، ولم تُختبر مفاتيح أو حسابات
خدمات حقيقية. دعم Custom لا يعني ضمان توافق كل endpoint أو موديل.
