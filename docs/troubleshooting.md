# حل المشكلات للمبتدئين

ارجع إلى [دليل الاستخدام](../README.md) لخطوات التشغيل الكاملة. ابدأ بالعرض الذي
تراه أدناه، ثم جرّب الحل بالترتيب. لا تحتاج تثبيت Python عند استخدام `RAT.exe`.

## البرنامج لا يفتح أو يتأخر في البدء

1. إذا كانت الملفات داخل ZIP، استعمل **استخراج الكل** ثم افتح الملف المستخرج.
2. افتح `dist/RAT.exe`؛ إذا استلمت EXE وحده افتحه مباشرة. لا تستخدم اختصارًا قديمًا
   يشير إلى مكان حُذف أو نُقل.
3. انتظر بدء النافذة قبل النقر مجددًا. يحتاج ملف التشغيل إلى فك مكتباته في مجلد
   Windows المؤقت، وقد يتأخر البدء.
4. إذا ظهرت النافذة سابقًا، راجع شريط المهام؛ ربما تكون خلف نافذة أخرى.
5. إذا ظهر خطأ مساحة أو كتابة، تحقق من وجود مساحة حرة على قرص النظام وعلى قرص
   مساحة العمل. شغّل الملف من مجلد محلي متاح لحسابك.
6. النسخة الحالية Windows x64. إذا كنت على نظام مختلف، راجع
   [حدود التوافق الفعلية](compatibility.md)؛ لم تُختبر كل الأنظمة.
7. إذا عرض Windows أو برنامج الحماية منعًا، احتفظ بنص الرسالة وراجع مصدر النسخة
   أو مسؤول الجهاز. لا تعطل برنامج الحماية لحل المشكلة.

إذا استمرت المشكلة، أرسل نص الرسالة ونسخة Windows ومكان تشغيل الملف وفق قسم
«طلب المساعدة» أدناه. تثبيت SDK أو إدخال مفتاح API ليس مطلوبًا لفتح الواجهة.

## إنشاء مشروع أو فتحه لا يعمل

| العرض | السبب المحتمل | خطوات الحل |
|---|---|---|
| حقول اللعبة معطلة | لا يوجد مشروع RAT مفتوح. | اضغط **إنشاء مشروع**، اكتب اسمًا، واختر مساحة عمل مستقلة. |
| «تعذرت العملية؛ تحقق من المسار والصلاحيات وصحة إعدادات المشروع» عند الإنشاء | اسم فارغ أو مكان لا يمكن الكتابة فيه، مثل مجلد محمي أو قرص غير متصل. | اكتب اسمًا غير فارغ واختر مجلدًا محليًا قابلًا للكتابة خارج اللعبة، مثل مجلد جديد داخل مستنداتك. |
| الرسالة نفسها عند الفتح | اختيار مساحة العمل الأم أو مجلد اللعبة، أو نقص ملفات المشروع. | افتح مجلد المشروع نفسه وتأكد من وجود `project.yaml` و`project.sqlite` معًا. اختر هذا المجلد في **فتح مشروع**. |
| الملفان موجودان والفتح يفشل | ملفات غير متطابقة، قاعدة تالفة، صيغة غير مدعومة، أو صلاحيات وصول. | أغلق البرنامج وانسخ مجلد المشروع كاملًا للحفاظ عليه، ثم جرّب نسخة احتياطية سليمة. إذا استمر الخطأ، اطلب المساعدة؛ لا تعدل YAML أو رقم مخطط قاعدة البيانات لتجاوزه. |
| لا أعرف أين حُفظ المشروع | مسار مساحة العمل نُسي. | إذا كان مفتوحًا، انسخ المسار بعد **المجلد:** أعلى النافذة. وإلا ابحث في مساحة العمل التي اخترتها عن `project.yaml` وافتح المجلد الذي يحتويه. |
| اسم المجلد أرقام وأحرف طويلة | هذا معرّف المشروع الذي ينشئه RAT. | استخدمه كما هو؛ اسم المشروع الذي كتبته يظهر داخل البرنامج. |

لا تحذف ملف SQLite أو تستبدله بملف من مشروع آخر. مجلد `exports` الفارغ طبيعي؛
وظيفة التصدير لم تُنفذ بعد.

## اختيار اللعبة والفهرسة والنتائج

| الرسالة أو العرض | المعنى | ما الذي تفعله؟ |
|---|---|---|
| «اختر مجلد اللعبة الذي يحتوي مجلد game» أو `missing_game_directory` | لم يُحدد مجلد مناسب، أو اختير `game` نفسه. | اختر المجلد الأب الذي يحتوي `game`. إذا لم يوجد، تحقق من موقع اللعبة ونوعها وفك ضغط الحزمة. |
| «مجلد اللعبة غير صالح أو رابط غير مسموح» أو `invalid_game_directory` | المسار غير موجود أو يشير إلى رابط غير مقبول. | اختر المجلد الحقيقي الموجود على القرص من زر **اختيار مجلد اللعبة**. |
| «يجب أن تكون مساحة مشروع RAT منفصلة عن مجلد اللعبة» أو `workspace_overlaps_game` | مشروع RAT داخل اللعبة أو اللعبة داخل مشروع RAT. | أنشئ مشروع RAT في مساحة أخرى مستقلة، ثم اختر اللعبة من موقعها الأصلي. |
| جدول فارغ بعد كتابة بحث أو اختيار فلتر | لا توجد وحدات تطابق جميع الشروط معًا. | امسح البحث، واختر **كل الأنواع** و**كل مستويات الثقة**. |
| عدد الملفات كبير وعدد النصوص صفر أو قليل | بعض الملفات أو صيغ النصوص غير قابلة للقراءة في هذه المرحلة. | اقرأ التحذيرات أدناه. جرّب عينة `tests/fixtures/game_with_tl` من الحزمة الكاملة للتأكد من خطوات الاستخدام. |
| `archives_not_extracted` | الفهرسة العادية رصدت `.rpa` دون استخراج. | افتح تبويب **الألعاب المجمعة / Packed** واضغط **Extract Packed Game**؛ راجع [دليل المرحلة 6](phase6.md). |
| `compiled_scripts_not_decompiled` | توجد `.rpyc` أو `.rpymc`؛ قد تتوفر مصادرها بالفعل. | يفحص تبويب Packed الملفات دون مصدر ويتيح محاولة فكها بعد التحقق من الإصدار. راجع unsupported/partial؛ لا تغيّر الامتداد. |
| `no_supported_text_source` | لم تُستخرج وحدات نصية مدعومة. | تحقق من المجلد ووجود مصدر أو قوالب عربية قابلة للقراءة؛ لا تفترض أن SDK سيفتح الأرشيفات. |
| `no_official_templates` | لم تتوفر قوالب عربية رسمية للقراءة في هذه العملية. | يمكن عرض نصوص المصدر قراءة أولية دون معرّفات. التوليد الاختياري يحتاج مصدرًا يدعمه الفحص وSDK مناسبًا. |
| `python_skipped` أو `python_modules_not_loaded` | رُصدت تعليمات أو وحدات Python وتُركت دون تنفيذ. | يمكن قراءة الأجزاء المدعومة؛ قد تبقى نصوص أخرى غير مكتشفة. هذه ليست مطالبة بتثبيت Python. |
| `unsupported_source_statement` أو `dynamic_screen_text_skipped` أو `unsupported_screen_literal` | توجد تعليمة أو صيغة نص غير مدعومة. | احتفظ برمز التحذير وموقعه عند الإبلاغ؛ وجود نتائج أخرى لا يعني اكتمال قراءة الملف. |
| `template_source_mismatch` | النص في القالب لا يطابق تعليمة المصدر المعروفة في الموضع المشار إليه. | استخدم مصدرًا وقالبًا من إصدار اللعبة نفسه. لا تعدل النص الأصلي أو المعرّف لتجاوز الاختلاف. |
| `unverified_template_source` | قُرئ نص القالب دون توثيق مطابقته للمصدر. | اعتبره نتيجة تحتاج تحققًا؛ قد يشير المسار والسطر إلى القالب نفسه. |
| `game_changed_during_scan` | تغير جرد الملفات أثناء الفهرسة. | انتظر انتهاء تحديث اللعبة وأغلق محرراتها، ثم أعد الفهرسة. لا تُستبدل النتيجة المحفوظة بهذه المحاولة الفاشلة. |
| `unsupported_encoding` أو `unsafe_or_large_source` | ترميز أو حجم أو نوع ملف لا يقبله القارئ. | لا تعدل أصل اللعبة. أرسل الرمز والمسار النسبي للمساعدة في تحديد الدعم المطلوب. |
| `inventory_entry_limit` أو `inventory_time_limit` أو `inventory_source_size_limit` | وصل الجرد إلى أحد حدود العدد أو الوقت أو حجم النصوص. | تأكد أنك اخترت مجلد اللعبة نفسها، لا مجلدًا يجمع ألعابًا كثيرة. إذا كان الاختيار صحيحًا، أبلغ عن الحالة. |
| `unreadable_game_directory` | لا يمكن قراءة أحد المجلدات. | تأكد أن القرص متصل وأن حسابك يستطيع الوصول إلى الملفات. استخدم مجلد لعبة محليًا يمكن قراءته. |
| `link_skipped` | تُرك رابط ملف أو مجلد دون اتباعه. | قد تكون التغطية ناقصة. استخدم المصدر الحقيقي في موقع مستقل مناسب عند توفره. |

عبارة **إصدار اللعبة: غير معروف** لا تمنع القراءة؛ RAT لا يخمّن الإصدار.
والرمز `—` في خلية يعني أن المعلومة غير متوفرة، وليس نصًا مفقودًا من القصة.
سلاسل القوائم قد تُعرّف بالنص الأصلي بدل معرّف حوار، حتى عند وجود قالب رسمي.

## مشكلات SDK وتوليد القوالب

إذا كان هدفك رؤية النصوص فقط، **أزل علامة «توليد قوالب arabic الرسمية على نسخة
عمل مستقلة» ثم أعد الفهرسة**. يمكنك بذلك قراءة المصادر والقوالب الموجودة دون SDK.

| الرسالة أو الرمز | المعنى والحل |
|---|---|
| «حدد مسار SDK أولًا» أو `sdk_required` | خيار التوليد مفعّل ولم تحدد SDK. اختر مجلده من **اختيار SDK** أو أزل علامة التوليد. |
| `invalid_sdk_directory` أو `invalid_sdk_layout` | حدد المجلد الرئيسي للحزمة الذي يحتوي `renpy.py` و`lib/py3-windows-x86_64/python.exe`. لا تختَر ملف تشغيل اللعبة أو مجلد `lib` وحده. الحزمة غير المكتملة أو ذات تخطيط آخر قد لا تكون مدعومة. |
| `sdk_unsafe_or_unsupported_source` | توجد تعليمات لا يقبلها فحص التوليد، مثل Python أو بعض تعليمات Ren'Py المتقدمة. استخدم الفهرسة العادية أو قالبًا عربيًا مناسبًا من صاحب المشروع. لا تحذف شيفرة اللعبة لتجاوز الخطأ. |
| `sdk_requires_complete_declarative_source` | يوجد أرشيف أو وحدة Python أو ملف مجمع بلا مصدر مقابل. التوليد الحالي مخصص للمصدر البسيط المكتمل؛ يمكن تجربة القراءة العادية. |
| `sdk_no_declarative_labels` أو `sdk_no_source_files` | لم يجد مسار التوليد المصدر أو بنية المشاهد التي يدعمها. جرّب عينة `tests/fixtures/sdk_project` مع SDK المختبر للتحقق من الإعداد. |
| `sdk_engine_version_mismatch` | عائلة إصدار SDK تختلف عن عائلة إصدار محرك اللعبة المكتشفة. استخدم حزمة مناسبة لمصدر اللعبة أو قالبًا موجودًا؛ لا تغيّر اسم مجلد SDK أو ملفات إصدار اللعبة لإخفاء الاختلاف. |
| `conflicting_engine_evidence` | معلومات إصدار المحرك في الملفات متعارضة. يلزم التحقق من نسخة المصدر قبل التوليد؛ تبقى القراءة دون توليد متاحة. |
| `unsupported_sdk_version` أو `sdk_platform_not_tested` | الإصدار أو المنصة خارج ما يقبله هذا المسار. الاختبار الفعلي الموثق هو SDK 8.5.3 على Windows x64؛ لا يوجد ضمان لإصدارات أخرى. |
| «انتهت مهلة SDK» أو `sdk_timeout` | انتهت مهلة الاستدعاء؛ لم تُعدَّل أصول اللعبة. تحقق من استجابة الجهاز ومساحة القرص، ثم جرّب العينة الصغيرة أو اكتفِ بالفهرسة العادية. |
| `sdk_start_failed` أو `sdk_command_failed` | تعذر تشغيل SDK أو أعاد أمره خطأ. تحقق من اكتمال الحزمة والمسار وصلاحيات الوصول، وجرّب العينة الصغيرة قبل لعبتك. إذا استمر الخطأ، أبلغ عن الرمز وإصدار SDK. |
| `sdk_no_templates_generated` أو `sdk_output_limit` | لم تنتج العملية قوالب قابلة للقراءة أو تجاوز إخراجها الحد المقبول. لا تُعتبر العملية ناجحة؛ احتفظ بالمعلومات واطلب المساعدة. |

التوليد لا يترجم النصوص. الملفات تحت `staging` نسخ عمل، وقد تتضمن نصوص واجهة
إضافية من SDK؛ لا تنسخها إلى لعبتك على أنها تعريب جاهز.

## عمود «حماية النص» يعرض «يحتاج مراجعة»

هذا يعني أن النص لم يجتز فحص الحماية، وليس أن البرنامج ترجم النص ترجمة سيئة.
انقر الصف واقرأ الرمز المسبوق بـ`protection/` في قائمة المشكلات أسفل الجدول.

| الرمز | ماذا يعني؟ |
|---|---|
| `unclosed_tag` أو `mismatched_tag` | يوجد وسم مفتوح دون إغلاق صريح أو تداخل غير متوازن. الفحص الحالي صارم حتى لو قبل المحرك بعض الإغلاقات الضمنية. |
| `unterminated_interpolation` أو `mismatched_bracket` | توجد أقواس متغير غير مكتملة أو غير متطابقة. |
| `unknown_tag` | نوع وسم غير معروف لسياسة الحماية؛ قد يكون وسمًا مخصصًا للعبة. يحتاج مراجعة من المطور، ولا يعني بالضرورة تلف اللعبة. |
| `invalid_conversion` أو `unsupported_format` | صيغة استبدال خارج النطاق المدعوم في هذه النسخة. |
| `reserved_marker_in_source` أو `unsupported_ruby` | النص يحتوي رموزًا محجوزة للحماية أو صيغة ruby لم تُدعم بعد. |
| رمز ينتهي بـ`limit` | النص تجاوز حدًا لحجم التحليل أو عدد أجزائه أو عمق تداخلها. |

احتفظ بالملف والسطر والرمز عند طلب المساعدة. لا تحذف الأقواس أو تعدل ملفات اللعبة
لتجعل الفحص ينجح. يمكنك متابعة استعراض بقية النصوص؛ الجاهزية للحماية ليست تعريبًا
مكتملًا. التفاصيل وحدود الفحص في [دليل المرحلة 2](phase2.md).

إذا كنت تستخدم Core وظهر `missing_marker` أو `duplicate_marker` أو `marker_order`
أو `unknown_marker`، فالمرشح لم يحافظ على الرموز كما هو مطلوب ويجب رفضه. لا تستبدل
الرموز يدويًا اعتمادًا على التخمين، ولا تستعمل نص استعادة فاشلة.

## البرنامج يبدو مشغولًا أو لا يسمح بالإغلاق

أثناء الفهرسة تُعطَّل بعض الأزرار ويُمنع إغلاق النافذة حتى تنتهي العملية. راقب
رسالة المرحلة فوق الجدول وانتظر؛ لا يوجد زر إلغاء في هذه النسخة. إذا استمر عدم
الاستجابة، دوّن آخر مرحلة ظاهرة والمدة التقريبية عند طلب المساعدة. إذا اضطررت
لإنهائه من إدارة المهام، افتح المشروع لاحقًا وتحقق من آخر نتائج محفوظة؛ لا تعتبر
الفهرسة التي قوطعت مكتملة.

## طلب المساعدة أو الإبلاغ عن مشكلة

أرسل المعلومات التالية لتسهيل التشخيص:

1. هل شغّلت `RAT.exe` أم الشيفرة؟ وما نسخة الحزمة التي استلمتها إن كانت معروفة؟
2. نسخة Windows ونوعه، مثل Windows 11 x64.
3. آخر زر ضغطت عليه، وما توقعت حدوثه، وما ظهر بدلًا منه.
4. نص الرسالة أو رمز التحذير كاملًا. لقطة شاشة اختيارية بعد إخفاء المعلومات الخاصة.
5. هل نجحت عينة `game_with_tl`؟ وهل خيار توليد القوالب مفعّل؟ وما إصدار SDK إن استُخدم؟
6. أنواع الملفات الموجودة مثل `.rpy` أو `.rpyc` أو `.rpa`، دون إرسال اللعبة كاملة.

السجلات والرسائل مختصرة عمدًا، وقد لا تحتوي تفاصيل السبب. لا تنشر مفاتيح API
أو أسماء مستخدمين ومسارات خاصة أو نصوص لعبة غير مخول بمشاركتها. انسخ مشروعك
احتياطيًا قبل محاولة فحص ملفات بيانات تالفة.

## مشكلات المزودين والترجمة — المرحلة 3

| الرسالة أو العرض | ما الذي تفعله؟ |
|---|---|
| `secure_storage_unavailable` | تعذر مخزن النظام الآمن. لا تضع المفتاح في YAML كحل بديل. تحقق من حساب Windows وإدارة بيانات الاعتماد، أو استخدم Mock إلى حين إصلاح المخزن. |
| `missing_key` | افتح **إعداد المزودين**، واختر المزود وأدخل المفتاح محليًا واحفظه. لا ترسله في بلاغ المشكلة. |
| `missing_model` | اختر **جلب الموديلات** بعد حفظ المفتاح، أو أدخل اسمًا متاحًا لحسابك. لا يكفي اسم الخدمة بدل الموديل. |
| `authentication` | صحح المفتاح وصلاحياته؛ المهمة لا تعيد تجربته على كل النصوص. استأنف مع تفعيل إعادة محاولة الفاشل. |
| `rate_limit` | المحرك يحترم Retry-After؛ خفّض التزامن وحجم الدفعات وطلبات/دقيقة بحسب حسابك. |
| `timeout`, `network_error`, `server_error` | تحقق من الاتصال والمهلة والخدمة، ثم استأنف المحفوظ. لا تبدأ مشروعًا جديدًا لمجرد خطأ شبكة. |
| `invalid_response` | الرد لم يحقق schema/IDs أو كان ناقصًا. تحقق من دعم الموديل وصيغة json_schema/json_object؛ JSON وحده لا يعني ترجمة صالحة. |
| `request_rejected` | قد تكون صيغة المخرج أو الموديل أو صلاحية الحساب غير مدعومة. راجع الإعدادات واختبر عينة قصيرة. |
| `validation_failed` أو `protection_failed` | لم تجتز النتيجة أو المصدر الحماية؛ لم تُحفظ ترجمة مقبولة لهذه الوحدة. لا تحذف الوسوم لتجاوز الخطأ. |
| `batch_size_limit` | ارفع الميزانية ضمن حدود الموديل أو قلل القاموس؛ المحرك لا يقطع داخل المتغيرات. |
| `google_failed` | الموصل غير الرسمي تعذر عليه قراءة خدمة Google. لا يوجد تحويل تلقائي إلى خدمة مدفوعة أخرى. |
| `missing_dependency` | عند تشغيل الشيفرة ثبّت `.[dev,llm]`. نسخة EXE الحالية تضم SDK؛ استخدم النسخة المحدثة. |
| Translated=0 و«محاكاة فقط» أكبر من صفر | هذه نتائج Mock، وليست ترجمة عربية. مهمة مزود حقيقي يمكنها استبدال محاكاة غير معتمدة. |
| لا تظهر الترجمة بجانب الأصل | شاشة المراجعة تخص المرحلة 4. النتيجة محفوظة في SQLite، والجدول الحالي يعرض المصدر وحالته. |
| الإيقاف لا يغلق فورًا | Pause/Stop ينتظران الطلبات الجارية وحفظها. انتظر انتهاء مهلة الطلب أو حفظه ثم أغلق مجددًا. |
| `translation_already_running` | يوجد محرك آخر على المشروع. أوقفه ثم استأنف؛ لا تشغّل عمليتي ترجمة على المشروع نفسه. |

بعد نقل المشروع لجهاز أو حساب Windows آخر، أدخل المفتاح محليًا؛ نسخ المشروع
لا ينسخ مفاتيح حساب النظام. اقرأ [دليل المرحلة 3](phase3.md) و[نتائج التحقق](phase3-verification.md).

## للمطور فقط: مشكلات بيئة Python

- عند تعذر تفعيل البيئة، شغّل `.venv\Scripts\python.exe` مباشرة؛ لا تحتاج تغيير
  سياسة تنفيذ PowerShell.
- إن فشل `py -3.11` أو `py -3.12`، افحص التثبيت عبر `py -0p`. يمكن استخدام
  Python 3.11+ متاح بعد مراجعة [التوافق](compatibility.md).
- تثبيت الاعتماديات يحتاج الوصول إلى مصدر حزم Python؛ نسخة EXE لا تحتاج هذه
  الخطوة. لا تستبدل Qt أو Pydantic بمحاكاة لتجاوز فشل التثبيت أو الاختبارات.
- عند تعذر Documents أو الكتابة فيه، حدد `--workspace` بمسار آخر قابل للكتابة
  عند إنشاء المشروع عبر CLI.
- اختبارات الواجهة تستخدم Qt `offscreen`. التشغيل العادي لا يفعّله؛ إذا ضبطت
  `QT_QPA_PLATFORM=offscreen` يدويًا في بيئتك، أزل ذلك الضبط عند تجربة نافذة فعلية.
