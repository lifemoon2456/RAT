# المرحلة 3 — المزودون ومحرك الترجمة

المتاح الآن: إعداد مزود، اختبار اتصال صريح، ترجمة النصوص المفقودة على دفعات،
حماية واستعادة وتحقق، قاموس CSV، ذاكرة ترجمة محلية، وحفظ مهمة قابلة للاستئناف.
لا يوجد محرر اعتماد أو تصدير أو تثبيت تعريب على اللعبة؛ هذه وظائف المرحلة 4.

## للمبتدئ: أول تجربة دون مفتاح أو إنترنت

1. شغّل `dist/RAT.exe`، وأنشئ مشروعًا وافهرس العينة أو اللعبة كما في README.
2. افتح تبويب **إعداد المزودين** واختر **Mock — محاكاة دون شبكة**.
3. اضغط **Test Connection — اختبار الاتصال**. ستظهر عبارة محاكاة محلية؛ لا يعني
   ذلك نجاح الاتصال بأي API خارجي.
4. افتح **الترجمة والتقدم** واختر Mock. يمكنك ترك باقي القيم الابتدائية.
5. اضغط **بدء مهمة جديدة للنصوص المفقودة**. تعرض العدادات Total وTranslated
   وRemaining وErrors، ومعها عداد مستقل **محاكاة فقط**.
6. مع Mock تبقى Translated صفرًا: المحاكاة تعيد الكلمات نفسها، بعد استعادة رموزها.
   تُحفظ نتيجتها بحالة needs_review، ولا تعتبر ترجمة عربية حقيقية.
7. النتائج محفوظة في SQLite. جدول النصوص الحالي يعرض الأصل والحالة، وليس محررًا
   يعرض الترجمة جنبًا إلى جنب؛ يمكن فحص translation_text عبر Core/قاعدة بيانات
   نسخة احتياطية، إلى حين إضافة شاشة المراجعة في المرحلة 4.

## إعداد مزود حقيقي

1. اختر المزود في **إعداد المزودين**.
2. أدخل مفتاح API في الحقل المخفي، ثم اضغط **حفظ الإعدادات والمفتاح**. لا ترسل
   المفتاح في المحادثات ولا تضعه في YAML أو CSV أو Base URL.
3. اضغط **جلب الموديلات** إذا كانت الخدمة تدعمه، أو اكتب الاسم المتاح لحسابك
   يدويًا. لا يتضمن البرنامج أسماء موديلات ثابتة أو وعدًا بحصة مجانية.
4. للخدمة المخصصة فقط، أدخل Base URL، مثل رابط ينتهي بـ`/v1` إذا كان خادمك
   يستخدم ذلك التخطيط. يسمح HTTPS، وHTTP للعناوين المحلية loopback فقط.
   لا يقبل الرابط اسم مستخدم/كلمة مرور أو query أو fragment. تغيير عنوان الخدمة
   المخصصة ينشئ هوية جديدة؛ المفتاح القديم لا ينتقل إلى عنوان آخر تلقائيًا.
5. اختر صيغة الرد التي يدعمها الموديل: json_schema أو json_object. DeepSeek
   يستخدم json_object دائمًا؛ ما زال الفحص المحلي يفرض البنية والمعرفات بدقة.
6. اضغط **Test Connection** لإرسال عينة قصيرة والتحقق من استجابة حقيقية وحماية
   رموزها. قد يُحسب الطلب من رصيدك. فشل المفتاح أو الموديل لا يعرض نجاحًا وهميًا.
7. افتح تبويب الترجمة واختر ملف المزود المحفوظ. عند البدء تُرسل النصوص المحمية
   والسياق المحدود والقاموس إلى الخدمة التي اخترتها. لا يوجد تبديل تلقائي لمزود آخر.

على Windows يستخدم التطبيق WinVaultKeyring من keyring لتخزين المفاتيح في مخزن
النظام. إذا تعذر المخزن، يتوقف الحفظ بدل إنشاء ملف أسرار نصي. لا تعاد المفاتيح
إلى حقل العرض. ترك حقل المفتاح فارغًا يحافظ على المفتاح المحفوظ لنفس ملف المزود.
نسخة المشروع الاحتياطية لا تحمل المفتاح إلى جهاز أو حساب Windows آخر؛ أدخله محليًا
هناك عند الحاجة. Custom يقبل خادمًا محليًا بلا مصادقة أيضًا.

## المزودون وحدودهم

| المزود | التنفيذ | ملاحظات |
|---|---|---|
| Mock | `providers/mock.py` | Echo دون شبكة؛ النتائج محاكاة فقط. |
| OpenAI | `providers/openai.py` | SDK `openai` الرسمي، Chat Completions، ومخرج JSON مضبوط حسب الخيار. |
| DeepSeek | `providers/deepseek.py` | SDK OpenAI إلى endpoint DeepSeek، مع JSON mode وفحص schema محلي. |
| OpenRouter | `providers/openrouter.py` | SDK OpenAI إلى endpoint OpenRouter؛ دعم schema يتبع الموديل/الخدمة. |
| Custom | `providers/openai_compatible.py` | Base URL وموديل ومفتاح مستقل، بلا افتراض توافق كل endpoint أو موديل. |
| Gemini | `providers/gemini.py` | SDK `google-genai` الرسمي، Developer API، وJSON Schema. |
| Google Translate | `providers/google_translate.py` و`google_worker.py` | `deep-translator` غير الرسمي؛ ليس Google Cloud Translation المدفوع الرسمي. |

Google Translate لا يطبق prompt أو سياقًا قصصيًا مثل LLM. تُحفظ رموز PH وGL محليًا
وتُترجم مقاطع اللغة الطبيعية بينها، ثم يعاد تركيبها وفحصها. يحافظ ذلك على الرموز
لكن قد يقلل جودة ترجمة جملة منقسمة بوسوم. ينفذ العامل في عملية فرعية تُقتل وتُنتظر
عند انتهاء المهلة؛ لا تُعدل المكتبة أو تُستخدم مهلة شكلية تترك thread شبكة معلقًا.
الحد العام للطلبات يُطبق على استدعاءات دفعات المزود، وقد يجري مسار Google عدة
طلبات للمقاطع داخل الدفعة؛ خفّض حجم الدفعة والتزامن عند استعماله. لا توجد حصة مجانية مضمونة.

## الدفعات والسياق والقاموس

تضبط الواجهة عدد عناصر الدفعة وميزانية الإدخال التقريبية والتزامن وطلبات/دقيقة والأسلوب.
التقدير يستخدم حجم JSON وUTF-8 ويشمل النص المحمي والسياق والقاموس مع هامش prompt؛
ليس عدد tokens مفوترًا. يدعم Core أيضًا حد المحارف وحجز tokens للمخرج وحد سياق
الموديل عند معرفته. الوحدة الأكبر من الميزانية تُعلّم للمراجعة، ولا تُقطع داخل
متغير أو وسم. إذا كانت استجابة JSON غير صالحة، يقسم المحرك الدفعة إلى دفعات أصغر
حتى الوحدة الواحدة؛ قد يزيد ذلك عدد الطلبات والتكلفة.

ContextBuilder يضم الشخصية وlabel والنص السابق واللاحق، حتى جملتين لكل اتجاه
من الملف والمشهد نفسه، أو سياق SourceUnit الصريح إن وجد. تُحمى حقول السياق أيضًا،
وتُحذف جملة سياق معطوبة أو أطول من الحد بدل قطع بنيتها. لا ترسل ملفات اللعبة كلها.

اختر قاموس CSV اختياريًا من شاشة الترجمة. مثال:

```csv
source,target,locked,case_sensitive,notes
Eileen,إيلين,true,false,اسم الشخصية
Academy,الأكاديمية,true,true,اسم مكان
```

الحد 1,000 مصطلح و256 KiB للملف. المصطلحات locked تُستبدل في النص العادي فقط
برموز GL مستقلة، ثم تُستعاد إلى target حرفيًا، مع فحص العدد والترتيب عبر جميع
رموز GL وPH. لا تُستبدل كلمات داخل متغير أو وسم أو جزء من اسم أطول.
المصطلحات غير المقفلة تُرسل إرشادًا إلى LLM، ولا يُضمن تطبيقها آليًا. تُرفض
مصادر/أهداف القاموس المحتوية على تراكيب Ren'Py أو رموز النقل؛ ليس القاموس مسارًا
لإضافة شيفرة إلى النص. تُحفظ نسخة القاموس والإعدادات في المهمة للاستئناف المتسق.

## التقدم وPause وResume وStop

- **Pause** يمنع بدء طلبات أخرى وينتظر الطلبات الجارية وحفظها، ثم يسجل المهمة paused.
- **Stop** يمنع العمل الجديد ويحفظ الجاري بالطريقة نفسها، ويسجل cancelled. لا يحذف
  النتائج أو ملفات المشروع؛ يمكن استئنافه بطلب صريح.
- **Resume** يستعمل ملف المزود والموديل والعنوان والإعدادات والقاموس الأصلي للمهمة.
  تعديل مفتاح الملف نفسه في مخزن النظام متاح لإصلاح انتهاء الصلاحية؛ لتغيير الموديل
  أو المزود أنشئ مهمة جديدة. لا تنقل resume إلى حساب خدمة أخرى تلقائيًا.
- لإعادة محاولة الوحدات failed/needs_review، فعّل المربع الخاص بها قبل الاستئناف.
  لا يُعاد تشغيل الوحدات المكتملة، ولا تُستبدل الترجمات الموجودة أو المعتمدة.
- استثناء مقصود: نتائج Mock غير المعتمدة يمكن استبدالها بطلب مزود حقيقي؛ لا تُعامل
  كترجمة جاهزة أو ذاكرة صالحة له. يحتفظ سجل المراجعات بالنتيجة السابقة.
- عند إغلاق النافذة أثناء العمل يطلب التطبيق Pause وينتظر حفظ الجاري؛ أغلق النافذة
  مجددًا بعد انتهاء العامل. بعد انقطاع مفاجئ افتح المشروع واختر المهمة ثم Resume.
- قد يعاد إرسال **الدفعة التي لم تُحفظ** عند انقطاع البرنامج أثناء طلب مدفوع؛
  SQLite يضمن سلامة البيانات المحلية، ولا يضمن منع فوترة طلب وصل إلى الخدمة قبل الانقطاع.

Total هو عدد وحدات المهمة. Remaining هو pending/in_progress، وErrors هو failed/needs_review،
وTranslated هو النتائج غير المحاكية المقبولة بنيويًا. تظهر المحاكاة والمحفوظ سابقًا/المستبعد
في عدادين مستقلين. completed مع Errors أكبر من صفر يعني انتهاء المرور مع مشاكل، لا اكتمال التعريب.

## Core والتخزين

`BaseTranslationProvider` يطبق واجهة `TranslationProvider` الأصلية، ويضيف دورة إغلاق
موارد SDK. لا يتغير عقد translate_batch: الاستجابة list[dict] مرتبطة بـunit_id.
يُفرض JSON schema محليًا حتى مع JSON mode، مع رفض المعرّفات الناقصة والمكررة والأجنبية.

`TranslationManager` ينظم الحماية والقاموس والسياق والدفعات والذاكرة والاستعادة
والتحقق والحفظ. قبل كل طلب تحفظ خريطة الحماية في job_items. الاستعادة الفاشلة
لا تصبح translation_text صالحًا؛ تحفظ المهمة فئة الخطأ وتبقى الوحدة للمراجعة.
النجاح البنيوي يحفظ real بحالة translated، وMock بحالة needs_review؛ لا يمنح validated أو approved.

مخطط SQLite الآن **v3**، مع ترقية v1/v2 ونسخة `project.sqlite.before-v3-*.bak`
قبل الترحيل. الجداول الجديدة: providers, jobs, job_items, tm_entries.
تُحفظ الترجمة وrevision وذاكرة الترجمة وحالة الوحدة في معاملة واحدة بعد الدفعة.
مفاتيح API لا تدخل هذه الجداول أو ملفات YAML أو checkpoints.

ذاكرة الترجمة داخل المشروع، ومفتاحها يشمل النص واللغة والهدف والنوع والسياق
والشخصية وlabel والأسلوب والقاموس والمزود والموديل والعنوان وسياسة الحماية.
تُراجع بنية النص المحفوظ قبل إعادة استخدامه. التكرارات ذات السياق المطابق تشترك
في طلب واحد؛ لا تدمج النصوص ذات الشخصيات أو السياقات المختلفة لمجرد تشابه العبارة.

قفل نظام تشغيل على مساحة المشروع يمنع محركي ترجمة متزامنين من عمليتين مختلفتين؛
يتحرر تلقائيًا عند موت العملية. يسمح المحرك بتزامن الدفعات داخل المهمة نفسها.
حدود المعدل خاصة بالمهمة، وليست حدًا عالميًا لحساب API عبر أجهزة ومشاريع متعددة.

RetryManager يعيد أخطاء الشبكة/المهلة و429 و5xx فقط، مع exponential backoff وjitter
وRetry-After. تُوقف أخطاء المصادقة توزيع الدفعات الجديدة دون تجربة المفتاح على كل النصوص.
تُعطَّل إعادة المحاولة الداخلية في SDK لتجنب مضاعفة المحاولات.

## CLI والتطوير

```powershell
# مطور يشغل الشيفرة؛ مستخدم EXE لا يحتاج التثبيت:
.\.venv\Scripts\python.exe -m pip install -e ".[dev,llm]"
.\.venv\Scripts\rat.exe providers --project "<RAT-project-folder>"
# دون profile => Mock فقط:
.\.venv\Scripts\rat.exe translate --project "<RAT-project-folder>"
.\.venv\Scripts\rat.exe translate --project "<RAT-project-folder>" --profile "<saved-profile-id>"
.\.venv\Scripts\rat.exe translate --project "<RAT-project-folder>" --job "<job-id>" --retry-failed
```

مفاتيح CLI تُدار عبر صفحة المزودين أو SecretStore، ولا يوجد وسيط API key يُكتب
في سطر الأوامر وسجل shell. لا توجد أوامر export أو install.
أخطاء المزودات تسجل في `logs/api.log` بفئة الخطأ واسم المزود فقط؛ لا يسجل النص
أو prompt أو headers أو المفتاح أو رسالة الاستثناء البعيدة. سجلات SDK الشبكية التفصيلية
معطلة في مسار المصنع. لا تفعّل تسجيل HTTP debug مع مفاتيح حقيقية.

## حدود التحقق والمراجع

pytest يعتمد على Mock وHTTP transports محاكية، ولا يحتاج مفاتيح أو إنترنت.
اختُبرت SDK المثبتة فعليًا، لكن **لم يُجر اتصال فعلي بأي حساب ترجمة**؛ لا توجد
مفاتيح اختبار مقدمة. نجاح اختبار اتصال من واجهتك بعد إعداد حسابك هو فحص مستقل
قد يستهلك رصيدًا، ولا يثبت جودة الترجمة أو توافق لعبة كاملة.
