# تشغيل الواجهة بملف EXE واحد

**تحديث Phase 7:** حزم 0.7.0b1 في `dist/release-0.7.0b1/`.
راجع [دليل التثبيت](installation.md) و[التحقق الحالي](phase7-verification.md).
أرقام الحجم والبصمة والاختبارات أدناه تخص بناء Phase 6 التاريخي، وليست إصدار Beta الحالي.

افتح `dist/RAT.exe` بالنقر المزدوج. المستخدم لا يحتاج Python أو pip أو PowerShell
أو الإنترنت للفهرسة وMock. الخدمات الحقيقية تحتاج اتصالًا وحسابًا عند اللزوم.
يمكن نقل ملف EXE وحده؛ لا يحتاج الملفات المصدرية أو `.venv` بجواره.
ملفات المشاريع مستقلة عنه ولا تُحفظ داخله. قد يستغرق فتحه ثوانٍ ريثما يفك المكتبات
المضمنة إلى مجلد النظام المؤقت، ثم يحذف مجلده المؤقت عند الإغلاق الطبيعي.

الوظائف المتاحة تشمل المراحل 0 إلى 6: إنشاء المشروع وفتحه، واكتشاف اللعبة وقراءة
النصوص والقوالب والبحث والحماية، وإعداد المزودين وترجمة دفعات محفوظة قابلة للاستئناف.
توليد القوالب يحتاج SDK خارجيًا ومصدرًا تصريحيًا
مدعومًا. الترجمة الفعلية تحتاج إعداد خدمة ومفتاحًا عند اللزوم؛ لم تُختبر مفاتيح حقيقية.
تشمل أيضًا المحرر والمراجعة وQA والبدائل والتصدير المستقل ونسخ مشروع RAT احتياطيًا.
توجد إعدادات خطوط وRTL وRuntime اختيارية ومعاينة وعينة SDK في تبويب العربية.
أضيف تبويب Packed لاستخراج RPA وتحليل RPYC المدعوم وحل التعارضات وتنظيف مساحة
التشغيل المحددة. لا يوجد تثبيت فوق اللعبة. راجع `phase5.md` و`phase6.md` للحدود.

## التحقق الفعلي — 2026-11-14

- بُني على Windows 11 x64 باستخدام Python 3.13.12 وPyInstaller 6.22.3.
- نجحت اختبارات pytest الـ**384** في **89.22s** مع SDK الحقيقي، دون تخطٍ أو فشل،
  و`ruff check` و`ruff format --check` قبل البناء. يشمل عدّ Ruff البالغ 278 ملفًا
  نسخ Python المولدة سابقًا داخل `build`.
- الحجم: **70,636,530 بايت**، نحو 67.4 MiB، وملف PE من نوع Windows GUI x64 دون console.
- نُسخ EXE وحده إلى مجلد مستقل، وشُغّل من مجلد عمل فارغ بعد إزالة `PYTHONHOME`
  و`PYTHONPATH` و`VIRTUAL_ENV` وحصر PATH في مجلد Windows System32.
- نجح الاختبار الذاتي داخل النسخة المجمعة: نافذة Qt، إنشاء مشروع وإغلاقه وفتحه،
  فهرسة مصدر تجريبي وتوليد قوالبه بالـSDK 8.5.3، وMock وإشعارات التراخيص،
  والحماية والاستعادة ورفض نص فاقد الرموز. عاد البرنامج برمز 0 وأكد `frozen: true`
  و`protection_verified: true` و`translation_manager_verified: true`.
- تحقق كذلك من حفظ الترجمة والاعتماد وQA والتصدير والنسخة الاحتياطية داخل EXE:
  `review_qa_verified: true`, `export_verified: true`, `backup_verified: true`.
  فُهرست 317 وحدة مع SDK، وصُدّرت وحدتا العينة المعتمدتان وبقي الأصل دون تغيير.
  تحقق كذلك من fontTools وAmiri ورخصته وRuntime والعينة:
  `arabic_font_verified: true`, `arabic_runtime_bundle_verified: true`.
  نتيجة الفحص الحالي في `.local/phase6-exe-check.json`، ومجلد العزل
  `.local/phase6-exe-385c2894`؛ التفاصيل في `phase6-verification.md`.
- تحقق EXE كذلك من أرشيفين مؤلفين محليًا، وفك RPYC مولد بالـSDK إلى وحدات ذات
  معرفات فعلية، وتنظيف مساحة التشغيل المحددة مع بقاء SQLite وبصمات أصول العينة:
  `packed_extraction_verified`, `rpyc_decompiler_verified`, `packed_cleanup_verified`
  كلها `true`. لا يشغّل مسار التحليل RPY أو RPYC أو Python من اللعبة.
- نتائج تجربة الرسم في المرحلة السابقة محفوظة في `phase5-verification.md`؛
  فحص EXE الحالي يتحقق من حزمة Runtime والعينة ولا يعيد تجربة الرسم كاملة.
- نُشئت وأُغلقت عملاء SDK OpenAI وGemini دون طلب شبكة، وشُغل عامل Google المجمّع
  على قائمة فارغة، وحُمّل WinVaultKeyring. لا يمثل ذلك اختبار حساب API أو تخزين مفتاح حقيقي.
- تمت هذه التجربة على الجهاز الحالي باستخدام Qt offscreen؛ لم يتوفر جهاز Windows
  نظيف دون Python لإجراء اختبار منفصل. لا يشمل ذلك Windows 10 أو ARM أو macOS.

## إعادة البناء للمطور

من جذر المستودع، بعد إعداد البيئة كما في README:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev,llm,windows-build]"
.\.venv\Scripts\python.exe scripts\build_windows.py
```

هذا الأمر يشغل الاختبارات والفحص، ويجمع إشعارات التراخيص، ثم يبني `dist/RAT.exe`.
يوجد أيضًا `scripts/build_windows.ps1` عندما تسمح السياسة المحلية بتشغيله؛ لا يلزم
تغيير سياسة أمان Windows، إذ يمكن استخدام نقطة الدخول Python مباشرة.

إعداد PyInstaller في `scripts/RAT.spec`، ولقطة اعتماديات بيئة البناء في
`requirements-windows-build-py313.lock.txt`. تحذيرات البناء عن `MySQLdb`, `psycopg2`,
`pysqlite2`, `tzdata` تخص واردات اختيارية لا تستخدمها الوظائف الحالية؛ اختُبر SQLite
المدمج فعليًا داخل EXE. ليست هناك حاجة لتثبيتها لتشغيل الواجهة الحالية.

لإعادة اختبار النسخة المجمعة مع إنشاء بيانات مصطنعة في مجلد مخصص:

```powershell
.\dist\RAT.exe --self-test ".local\exe-check"
```

الناتج في `.local/exe-check/result.json`. هذا وضع فحص صريح؛ التشغيل العادي لا
ينشئ مشروعًا تجريبيًا. تعرض قائمة «مساعدة ← تراخيص المكتبات» النصوص المضمنة.
