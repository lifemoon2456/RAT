## ما تحقق

- حماية النصوص العادية والعربية، والمتغيرات المتعددة والمتكررة، وأعلام التحويل
  والتنسيق، والفهارس والأقواس المتداخلة والاقتباسات داخل التعبير.
- حماية الوسوم المتداخلة واللون وstyle وfeature والوسوم المنفردة والسياقية،
  ووسم يحوي استبدالًا في وسيطه، دون تنفيذ معالجات أو تعبيرات اللعبة.
- استعادة حرفية بعد JSON roundtrip، بما فيها `[[`, `{{`, `%%`, LF, CRLF,
  tab والشرطات العكسية، وحدود الهروب القريبة من المتغيرات والوسوم.
- رفض الرموز المفقودة والمكررة والمشوهة والأجنبية والمعاد ترتيبها، ورفض
  إضافة متغير أو وسم خام خارج الرموز، أو تغير البنية بعد الاستعادة.
- رفض الوسوم المتقاطعة والمفتوحة والزائدة، والأقواس والتعبيرات المعطوبة،
  والترجمة الفارغة، والخرائط المعدلة، والوحدة/نسخة المصدر غير المطابقة.
- إرجاع أخطاء منظمة بنوع المشكلة والنص المتأثر والموضع والمرحلة؛ لا يعاد
  نص مقبول عند الفشل (`RestorationResult.text is None`).
- حدود لحجم النص وعدد tokens وعمق التداخل وطول رد النقل.
- Mock يغير ترتيب النتائج كما كان، ويُربط الرد بـunit_id ثم تُفحص الاستعادة؛
  لا تُستعمل فهارس قائمة الرد لربط النصوص. اختبارات التكامل تمنع طلبات HTTP
  والشبكة الخارجية بالمحاكاة أثناء هذا المسار.
- مقارنة كل ملفات عينة اللعبة، أسماءً وبايتات، قبل الاستيراد والحماية وإعادة
  الفتح والاستيراد وبعدها؛ لم يتغير أي ملف أصل أو يظهر ملف جديد داخله.
- مقارنة `units.source_data` في SQLite قبل الحماية وإعادة الاستيراد وبعدهما؛
  لم تتغير الحقول أو البصمة، وأعيد استخدام الوحدات الثماني دون إضافة نسخ.
- رفض مرشح فاقد الرموز مع بقاء الترجمة المعتمدة وسجل مراجعاتها كما هما.
- واجهة Qt تعرض حالة الحماية ومعاينة الصف المختار بعد البحث والتصفية؛ وCLI
  `protect` يستخدم الوحدات المحفوظة دون تغيير بايتات قاعدة البيانات أو تسريب النص للسجل.

حُدث اختبارا ثبات تقرير الاستيراد لاستثناء `protection` المشتق من مقارنة
snapshot: namespaces تتجدد عند التحميل. لا يُستثنى المصدر أو الوحدات أو provenance
أو بيانات الجرد المحفوظة. توجد اختبارات مستقلة لثبات بيانات SQLite وملفات اللعبة.

## الملفات الجديدة

- `src/rat/domain/protection.py`: عقود tokens والخرائط والأخطاء والنتائج والوحدات.

  وكشف الاستبدالات وسياسة الوسوم وتوازنها.

- `tests/fixtures/placeholders/cases.json`: أمثلة نصوص سليمة ومعطوبة متاحة دون شبكة.
- `tests/unit/test_protection.py`, `tests/integration/test_protection_flow.py`:
  اختبارات الوحدة والتكامل والتحقق من ثبات المصدر.
- `docs/phase2.md`, `docs/phase2-verification.md`: تصميم المرحلة وحدودها ونتائجها.

## القيود المتبقية

الفحص يفرض ترتيبًا صارمًا للمتغيرات وإغلاقًا صريحًا للوسوم الزوجية؛ قد يرفض
نصوصًا يقبلها المحرك أو صياغة لغوية تتطلب تغيير ترتيب المتغيرات. الوسوم المخصصة
تحتاج تعريف أسماء وأدوار ساكنًا من المطور، وruby غير المهرب والتنسيقات الديناميكية
المتداخلة خارج النطاق. النحو والقيم المتقدمة ليست كلها مدعومة؛ راجع `phase2.md`.

الحماية تعمل على النص المفكوك، ولا تُنشئ ملفات `.rpy` ولا تفحص مسارات الموارد أو
جودة اللغة أو مظهر العربية. لا تُمنح حالة validated للتصدير بسبب نجاحها.
الخرائط في الذاكرة قابلة للتسلسل؛ حفظها لمهام API واستئنافها يخص مرحلة لاحقة.
لم تُختبر ألعاب حقيقية أو كل إصدارات Ren'Py أو Python أو جهاز Windows نظيف.
