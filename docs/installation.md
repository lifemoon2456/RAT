# RAT 0.7.0b1 — Windows Beta

Windows x64، للاختبار. لا يحتاج المستخدم Python أو pip. اختر من `dist/release-0.7.0b1/`:

- `RAT-0.7.0b1-windows-x64-setup.exe`: مثبت خاص بالمستخدم، دون طلب Administrator.
- `RAT-0.7.0b1-windows-x64-portable.zip`: فك ZIP ثم افتح `RAT.exe`.

النسخة Portable قابلة للنقل، لكن إعداداتها ومشاريعها لا تُحفظ بجانب EXE.
الإعدادات في `%LOCALAPPDATA%\RenPyArabicTranslator\settings.yaml`، والسجلات
في مسار المستخدم الذي تعرضه «مساعدة ← حول البرنامج». المشاريع في Documents
أو المجلد الذي تختاره. يحتفظ البرنامج بآخر مجلد عمل مختار. لا يحتاج الكتابة
في Program Files. المفاتيح في Windows Credential Manager، ولا يوجد fallback نصي.

للتحديث اليدوي: أغلق RAT بعد انتهاء العمل الجاري، وأنشئ نسخة احتياطية للمشروع،
ثم شغّل المثبت الجديد أو استبدل EXE المحمول. لا تستبدل مجلدات المشاريع.
إزالة التطبيق تترك المشاريع والإعدادات والمفاتيح في مخزن النظام كما هي.
لا يوجد تحديث تلقائي أو تنزيل شيفرة عند التشغيل.

من تبويب «التصدير والنسخ الاحتياطي»:

1. صدّر النصوص المعتمدة إلى حزمة مستقلة وراجع التقرير.
2. النسخة الاحتياطية تحفظ SQLite والبيانات والخطوط والقوالب المحفوظة؛ لا تشمل
   ملفات اللعبة أو مفاتيح النظام أو exports القديمة.
3. «استعادة نسخة مشروع» تنشئ مشروعًا جديدًا؛ افتحه باستخدام «فتح مشروع».
4. «تثبيت آخر حزمة مكتملة» ينشئ مجلدًا جديدًا يحتوي `game-copy/` و`backup/`
   و`installation.json`. شغّل نسختك من `game-copy` فقط بعد الفحص.
   يتطلب مساحة لنسخة اللعبة كاملة، ويرفض الروابط وتغيّر المصادر والحزم الجزئية.
   متاح لاستيراد المصدر؛ ألعاب Packed تظل تُصدّر كحزمة منفصلة للمراجعة اليدوية.
5. أغلق اللعبة قبل «استعادة ملفات نسخة اللعبة». تعاد الملفات السابقة وتزال
   ملفات RPYC المقابلة التي ولدها المحرك أو تستعاد نسخها السابقة. تتوقف الاستعادة
   إذا عدّلت ملف الترجمة المثبت يدويًا؛ احتفظ بتعديلاتك خارجيًا أولًا.
6. تقرير التشخيص يحفظ JSON في reports: إصدارات وأعداد فقط، دون النصوص أو المفاتيح
   أو headers أو المسارات أو نسخ logs. راجعه قبل مشاركته.

بعد الانقطاع، افتح المشروع واستأنف المهمة المحفوظة. تعاد الوحدات غير المكتملة
فقط؛ الاعتماد السابق محفوظ. قد يعاد طلب API لم تُحفظ استجابته قبل الانقطاع.
إذا انقطع التثبيت بعد journal بحالة `prepared`، استخدم استعادة النسخة.
إذا انقطع نسخ اللعبة قبل journal، فالمجلد الجديد غير مكتمل؛ لا تشغّله. الأصل سليم.
إذا فشلت استعادة المشروع، تبقى `.rat-restore-*` غير منشورة للفحص.

SDK اختياري وخارجي لتوليد القوالب واختبارات المحرك. الحزمة تتضمن موصلات
OpenAI/Gemini/deep-translator؛ لا يلزم pip داخل EXE. الخدمات تحتاج إعدادًا وحسابًا
واتصالًا؛ Mock محاكاة بلا شبكة. DeepL/Cloud/Argos ليست وظائف متاحة في الواجهة الحالية.

فحص `SHA256SUMS.txt` يثبت مطابقة ملفك لملف الإصدار، ولا يحل محل توقيع الناشر.
هذه النسخة غير موقعة. نتائج التحقق وحدود الجاهزية في `phase7-verification.md`.

## إعادة البناء

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev,llm,windows-build]" -c requirements-windows-build-py313.lock.txt
$env:RAT_RENPY_SDK = 'C:\Tools\renpy-sdk'
.\.venv\Scripts\python.exe scripts\build_windows.py
.\.venv\Scripts\python.exe scripts\prepare_release.py --compiler 'C:\Tools\Inno Setup\ISCC.exe'
```

احذف تعيين SDK إن لم يتوفر؛ ستظهر اختباراته كمتخطاة صراحة.
المكافئ: `scripts/build_windows.ps1 -Compiler <ISCC.exe>`.
لا تضع مفتاح API في الأوامر أو ملفات البناء. احفظ المصادر والتراخيص مع الإصدار.
يرفض prepare_release EXE لا يطابق نتيجة اختبار النسخة الحالية.
