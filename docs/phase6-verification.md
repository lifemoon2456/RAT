## ما تحقق

اختُبرت أرشيفات RPA-2 وRPA-3 ببيانات صغيرة أصلية مؤلفة للاختبار: عدة أرشيفات،
المسارات المتداخلة وUnicode وprefix، الحفاظ على محتوى الملفات وبصماتها، تعارضات
الأسماء واختلاف حالة الأحرف وتعارض الملف/المجلد، منع traversal وأسماء Windows
المحجوزة، الحدود والملفات المعطوبة، الملفات المتطابقة، وعزل الألعاب والتشغيلات.

اختُبرت حماية pickle من reducers تنفيذية ومن توسع الحاويات والتجزئة المكلفة بمراجع
متداخلة، وحدود فك الضغط والنص الناتج. لا يستخدم قارئ المدخلات unpickle التنفيذي.
اختُبرت بوابة التوافق قبل المحول، وعدم فك ملف له مصدر مقابل، والإبلاغ عن غير المدعوم.

استُخدم SDK الحقيقي **8.5.3.26051504** الذي حدده المالك لتجميع نصوص RAT المؤلفة
إلى RPYC. فُك ملف العينة إلى **8 وحدات** وحُفظت **6 معرفات حوار فعلية** منها
`start_1b4a9f2d`، ثم مرّت الوحدات بمحللات المرحلة 1 وحماية المرحلة 2. اختُبر ملف
يحوي عقدة Python ذات علامة اختبار: لم تُنشأ العلامة، وحُذفت الشيفرة من ناتج التحليل،
وسُجلت النتيجة جزئية. لا يُشغل مسار التحليل لعبة أو RPYC؛ التجميع في الاختبار يقتصر
على مشروع RAT المؤلف محليًا، ولا تستخدم fixtures محتوى لعبة تجارية.

اختُبر كذلك مصدر تصريحي مستخرج مع توليد قالب رسمي بالـSDK في staging جديد،
وإنشاء عينة Runtime بعد استيراد packed، دون تغيير ملفات المدخل. اختُبر تنظيف تشغيل
واحد مع بقاء ترجمات **8 وحدات معتمدة** وإمكان تصديرها من لقطة القالب المخزنة،
وبقاء كل بصمات ملفات الأصل مطابقة. رُفض استيراد view عُدّل ورُفض manifest مزور
يحاول توسيع مسار التنظيف. اختُبر أن استعادة بلا نص مدعوم لا تمحو فهرسة سابقة.

اختبارات PySide6 تغطي الاستخراج والعدادات والفهرسة والتنظيف، والاختيار الصريح
للملف المتعارض وتطبيقه. اختبارات CLI تغطي extract وinfo وclean. فُحصت الواجهة
بصريًا عبر منصة Qt windows؛ اللقطة المحلية `.local/phase6-preview-3e73b568/packed-page.png`.

## الحدود الباقية

المحول المرفق محدود وليس بديلًا كاملًا لـunrpyc؛ لم تُضمّن أو تُشغل أداة خارجية.
التجربة الحية لفك RPYC على **8.5.3 فقط**. العائلات الأخرى المسموحة تحمل تحذيرًا؛
القديم والمجهول والمتعارض وخارج العائلة محجوب. العقد غير المدعومة تجعل الاستعادة
جزئية، ولا تُنفذ Python لتوسيع التغطية. RPA المموه أو المشفر أو ذو الصيغة غير
المدعومة يُرفض. لا ضمان للوصول إلى النصوص الديناميكية أو لكل واجهات اللعبة.

تبويب Packed لا يولد قوالب SDK تلقائيًا؛ Core يوفر ذلك فقط لمصدر تصريحي كامل
موثق. لا يمكن تصدير نصوص دون قوالب رسمية مطابقة، ولا نولد IDs مخمنة لتعويضها.
لا اختبار لعبة تجارية، أو جهاز Windows نظيف دون Python، أو Linux/macOS.
لا تثبيت تعريب فوق اللعبة ولا تحديث لمحركها ولا بداية للمرحلة 7.
