# التوافق وحدود التحقق

الهدف Windows 10/11 64-bit وPython 3.11+، مع تفضيل بدء مصفوفة الاختبار بـ3.11 و3.12.
هذه حدود مستهدفة، وليست ادعاء باختبار كل توليفة.

بيئة التنفيذ المتاحة خلال تأسيس المرحلة 0: Windows 11 (build 26200) وPython 3.13.12.
تثبيت Python 3.12 المسجل في WindowsApps لم يعمل برسالة Access is denied؛ لذلك
لم يتم التحقق على 3.11 أو 3.12، ولم يتم تعديل تثبيت Python أو سياسات أمان النظام.

اختبارات الواجهة آلية عبر Qt offscreen. لا تغني عن مراجعة بصرية للعربية على
شاشة Windows فعلية. لم يتوفر اختبار على Windows نظيف. أضيف لاحقًا EXE مستقل
بطلب المالك، ثم حُدث مع المراحل المنفذة واختُبر على الجهاز الحالي؛ راجع `windows-exe.md`.
في بيئة الاختبار لم يجد offscreen خطوطًا نظامية. جرى التحقق من لقطة إضافية عبر
منصة Qt الأصلية `windows` بنافذة لا تُعرض على الشاشة؛ ظهرت فيها العربية مع خط
Segoe UI. هذه معاينة للواجهة الأولية فقط، وليست اختبار تنضيد داخل لعبة Ren'Py.

في المرحلة 1 اختُبر SDK الحقيقي Ren'Py **8.5.3.26051504** من المسار الذي حدده المالك،
على مشروع RAT تجريبي تصريحي مؤلف محليًا. وُلدت قوالب فعلية على نسخة staging وقُرئت
معرّفاتها ومواقعها، واختُبرت LF وCRLF. قالب `game_with_tl` ناتج SDK فعلي موثق في
`provenance.json`؛ العينة القديمة `source_unit.json` تظل عينة مصطنعة للمرحلة 0.
لم تُفتح أو تُشغّل لعبة حقيقية، ولم تُختبر 8.2 أو 8.3 أو 8.4 أو 7.x أو SDK على Linux.
كان ذلك تحقق المرحلة 1؛ تحقق التصدير اللاحق موضح أدناه.

لم تُختبر خدمات ترجمة أو مفاتيح API. لا توجد خطوط أو شيفرة خارجية منسوخة إلى
المشروع، ومجلدات الأيقونات والخطوط محجوزة فقط. يحتوي EXE الحالي إشعارات تراخيص
الاعتماديات ونصوص رخص Qt، دون خطوط أو مكتبات منسوخة من ألعاب.

في المرحلة 2 اختُبرت الحماية والاستعادة ورفض التلاعب بالرموز وربطها بوحدات المرحلة 1.
سياسة الوسوم مبنية على أسماء وأدوار SDK 8.5.3؛ الفحص أكثر صرامة في الإغلاق الصريح
وترتيب المتغيرات، ويرفض الوسوم المخصصة غير المسجلة وruby غير المدعوم. لا ينفذ
التعبيرات، ولا يثبت نجاحه جودة الترجمة أو تشغيل تعريب. التفاصيل في `phase2.md`.

في المرحلة 3 اختُبرت OpenAI SDK **2.54.0** وGoogle GenAI SDK **1.75.0**
باستجابات HTTP محاكية، وdeep-translator **1.11.4** بعامل وناقل محاكيين.
اختُبر محرك 120 وحدة على Mock مع توقف واستئناف من عملية جديدة، وترحيل SQLite v2
إلى v3. لا توجد مفاتيح اختبار حقيقية، ولم يتحقق وصول شبكي إلى حسابات المزودات أو
جودة ترجمتها أو حدودها المجانية. تنفيذ الموصل لا يعني ضمان توافق كل موديل أو endpoint.

في المرحلة 4 اختُبر المحرر وQA والبدائل والتصدير وإعادة الاستيراد وحفظ المعرفات،
وترقية SQLite إلى v4. شُغل SDK **8.5.3.26051504** على نسخة من عينة RAT المؤلفة
محليًا بعد وضع الملفات المصدرة فيها: compile ثم أمر تشخيص محلي يتحقق من تحميل
6 معرّفات حوار وسلسلتي old/new واستبدال player_name. شيفرة التشخيص مؤلفة للاختبار
فقط، ولا تُستخرج من لعبة، ولا يفعّل RAT تنفيذ Python أثناء الاستيراد أو التصدير.
هذا اختبار تحميل ونصوص فعلي داخل المحرك، وليس لعبًا بصريًا كاملًا أو اختبار خطوط
أو RTL. لم تختبر لعبة تجارية أو إصدارات أخرى. انظر `phase4-verification.md`.

في المرحلة 5 شُغل مشروع Runtime الأصلي لـRAT على SDK **8.5.3.26051504** بمحرك
الرسم gl2 على Intel Iris Xe. نجح compile وlint وتشغيل ورسم الحوارات والنصوص
المختلطة بـAmiri/HarfBuzz، والتعطيل وإعادة التفعيل وتبديل اللغة واستعادة الأنماط.
راجعت لقطات الحوار والشخصية ونماذج الخيارات وHistory وPreferences. هذه تجربة
مرئية فعلية للعينة، ولا تثبت توافق ألعاب تجارية أو واجهات مخصصة أو كل المحارف
المحتملة في قيم المتغيرات. Qt preview يظل تقريبيًا.

ملفات توافق 8.2–8.3.6 و8.4+ مبنية على خصائص موثقة، مع تحذير أنها لم تختبر حيًا
عدا 8.5.3. سلسلة 8.3 من 8.3.7 محجوبة تحفظيًا بسبب مشكلة bidi موثقة، و7.x
و8.0/8.1 غير متحققة لهذا المسار. لا reshaping أو عكس يدوي، ولا تحديث محرك لعبة.
الخط المرفق Amiri الأصلي تحت SIL OFL 1.1؛ التغطية تفحص fontTools 4.68.0.
التفاصيل والنتائج في `phase5-verification.md`.

في المرحلة 6 اختُبرت حاويات RPA-2/RPA-3 ببيانات أصلية صغيرة مؤلفة للاختبار، وملفات
RPYC مولدة محليًا بواسطة SDK 8.5.3.26051504. مسار AST خامل ومحدود، مع منع Python
وغياب أي أداة فك خارجية مرفقة. العائلات 8.2–8.5 الأخرى غير مختبرة حيًا ويظهر تحذير،
والإصدار المجهول/المتعارض أو القديم أو الأحدث خارج العائلة يمنع محاولة الفك. لم تستخدم
ألعاب تجارية أو محتوياتها في fixtures، ولم تختبر الصيغ المموهة أو كل عقد Ren’Py.
انظر `phase6.md` و`phase6-verification.md`؛ لا يعني نجاح القراءة قابلية تشغيل view كلعبة.
