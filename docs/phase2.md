# المرحلة 2 — حماية نصوص Ren'Py

النظام مستقل عن Qt وقاعدة البيانات والشبكة. يعمل على `source_text` المفكوك من
string literal في المرحلة 1، ولا يقرأ أو يكتب ملفات اللعبة. لا يعيد فك escaping
من `source_literal`؛ يبقى التمثيل الأصلي محفوظًا دون تغيير.

## الوحدات والعقود

| الوحدة | المسؤولية |
|---|---|
| `TextTokenizer` في `protection/tokenizer.py` | مسح النص بحالات منفصلة للنص والأقواس والهروب، مع مواقع Unicode بنظام start شامل وend غير شامل. |
| `PlaceholderDetector` في `protection/placeholders.py` | قراءة حدود الاستبدالات وتداخل الأقواس والاقتباسات وأعلام التحويل والتنسيق، وحقول percent التقليدية. |
| `TagProtector` في `protection/tags.py` | سياسة أسماء الوسوم وأدوارها، وفحص المكدس والإغلاق بالترتيب العكسي للفتح. |
| `MaskingEngine` في `protection/masking.py` | استبدال كل ظهور لعنصر محمي برمز نقل مستقل وحفظ النص والموقع والنوع في خريطة الاستعادة. |
| `ValidationEngine` في `protection/validator.py` | فحص سلامة الخريطة والرموز وأعدادها وترتيبها، ثم تحليل النص المستعاد ومقارنة البنية. |
| `RestorationEngine` في `protection/restoration.py` | استعادة آمنة بمرور واحد بعد نجاح الفحص؛ يعيد `text=None` عند أي رفض. |
| `ProtectionService` في `protection/service.py` | ربط الخريطة بـunit_id وبصمة المصدر، وتجهيز الوحدات المستخرجة وفحص الترجمات الموجودة. |

نماذج Pydantic المجمدة في `domain/protection.py`: `ProtectionIssue`, `TextToken`,
`TokenizationResult`, `ProtectedToken`, `ProtectedText`, `MaskingResult`,
`ValidationResult`, `RestorationResult`, `UnitProtection`.
تتيح النتائج خاصية `valid`، وتتيح وحدة الحماية خاصية `ready`؛ يجب فحصها قبل الاستعمال.

## ما يُحمى

- متغيرات مثل `[player_name]`, `[score!s]`, `[points:03d]`, `[mood!t]`، وفهارس
  متداخلة مثل `[player.names[0]]`، واقتباسات داخل التعبير وأقواس في القيم المقتبسة.
- أعلام تحويل Ren'Py 8.5.3 المعروفة `r/s/t/i/q/u/l/c` ومجموعاتها، وتنسيق ثابت
  بعد `:`. التعبير يُفحص نحويًا باستخدام `ast.parse` فقط؛ لا تُحسب قيمته ولا تُحل
  أسماء المتغيرات أو تُستدعى الدوال، حتى إذا احتوى استدعاءً في نصه.
- الوسوم الزوجية المعروفة، ومنها b/i/color/font/size/a، وstyle مثل `{=my_style}`
  مع `{/}`، وfeature مثل `{feature:liga=0}`، ووسم السياق `{#playlist}`.
- وسوم منفردة مثل `{w}`, `{p}`, `{nw}`, `{image=heart.png}`. الوسم الذي يحتوي
  استبدالًا في وسيطه، مثل `{a=[target]}`، يُحمى كعنصر كامل مع فحص حدود الاستبدال.
- `[[`, `{{`, `%%` بوصفها أزواج هروب مستقلة، وحقول percent مثل `%(name)s`
  و`%(score)03d` وبعض الحقول الموضعية مثل `%s`. التعرف على percent محافظ؛ قد
  يحمي نمطًا مطابقًا نحويًا ولو كان الكاتب يقصده كنص عادي.
- الأسطر الحقيقية LF وCRLF وعلامة tab، والشرطات العكسية الحرفية. تحافظ الخريطة
  كذلك على تسلسلات حرفية مثل backslash+n إن كانت موجودة في النص المفكوك.
  الشرطة العكسية الحرفية لا تخفي استبدالًا أو وسمًا يليها.

لا يستخدم المحلل Regex لاستخراج كل الأقواس، ولا يستورد Ren'Py أو Python من اللعبة.
الاقتباسات العادية داخل النص المفكوك ليست حدود ملف `.rpy`؛ escaping عند كتابة
ملفات التصدير مسؤولية المرحلة 4، وليس هذا النظام.

## الخريطة وسياسة القبول

لكل عملية حماية namespace عشوائي UUID. المثال الشكلي للرمز:
`⟦PH_<namespace>_0001⟧`. تكرار `[name]` مرتين ينتج رمزين مختلفين، ولكل منهما
موضعه الأصلي. هذه رموز نقل مؤقتة، وليست معرّفات ترجمة Ren'Py.

تحتوي `ProtectedText` على النص الأصلي وبصمة SHA-256 له والنص المحمي والعناصر
المرتبة. يمكن تسلسلها إلى JSON وإعادة تحميلها. قبل الاستعادة يعاد فحص البصمة
والمواقع والأنواع والرموز وتطابق النص المحمي مع المصدر؛ تعديل الخريطة دون اتساق
يؤدي إلى `invalid_protection_map`. عند العمل مع وحدة مستخرجة، استخدم
`restore_unit` لرفض خريطة تخص وحدة أو نسخة مصدر مختلفة.

1. يجب أن يظهر كل رمز معروف **مرة واحدة بالضبط**.
2. تُرفض الرموز المفقودة والمكررة والأجنبية أو المشوهة.
3. **الترتيب مطابق للمصدر لكل العناصر المحمية، بما فيها المتغيرات** وفق الطلب
   المباشر لهذه المرحلة. كلمات النص العادية قابلة للترجمة دون ترتيب مفروض.
   قد ترفض هذه السياسة إعادة ترتيب متغيرات صحيحة لغويًا؛ لا يوجد خيار لتجاوزها الآن.
4. يُستعاد النص بمرور واحد، ثم يُحلل من جديد. يجب أن تتطابق قائمة العناصر
   المحمية حرفيًا، ونوعًا، وعددًا، وترتيبًا. يكتشف ذلك إضافة `[other]` أو `{b}`
   خارج الرموز وتغير معناها عند حدود `[[` و`{{`.
5. يُفحص توازن الوسوم مرة أخرى، وتُرفض ترجمة فارغة بدل مصدر غير فارغ.
6. لا يعاد نص مقبول جزئيًا عند الخطأ. النجاح فحص بنيوي، ولا يضمن جودة اللغة
   أو صحة قيم الوسوم أو صلاحية ملف تصدير أو تغطية اللعبة.

## الأخطاء المنظمة

كل `ProtectionIssue` يحمل `code`, `affected_text`, `start`, `end`, `message`,
و`stage` بقيمة source/translation/mapping. النص المتأثر قد يكون الرمز المتوقع
عند فقدانه؛ في هذه الحالة ليس نطاقًا موجودًا داخل الترجمة. أخطاء المقارنة العامة
قد تشير إلى النص الكامل، وأخطاء التحليل تحمل موضعها في النص الذي حُلّل.
لا يكتب النظام هذه النصوص في logs.

| أمثلة الرموز | المعنى |
|---|---|
| `unterminated_interpolation`, `mismatched_bracket`, `invalid_expression` | استبدال ناقص أو أقواس/تعبير غير صالح للحماية. |
| `invalid_conversion`, `unsupported_format` | علم تحويل أو تنسيق خارج النطاق المدعوم. |
| `unterminated_tag`, `malformed_tag`, `unknown_tag` | وسم ناقص أو صيغة غير مقبولة أو دور غير معروف. |
| `unclosed_tag`, `unexpected_closing_tag`, `mismatched_tag` | إغلاق مفقود أو زائد أو تداخل متقاطع. |
| `missing_marker`, `duplicate_marker`, `unknown_marker`, `malformed_marker` | تلف بروتوكول الرموز المؤقتة. |
| `marker_order`, `protected_structure_changed` | اختلاف ترتيب الرموز أو بنية النص بعد الاستعادة. |
| `invalid_protection_map`, `unit_protection_mismatch` | خريطة غير متسقة أو مرتبطة بوحدة/نسخة أخرى. |
| `empty_translation`, `invalid_translation_type` | ترجمة فارغة غير مقبولة أو استجابة ليست نصًا. |

## الربط بالمرحلة 1 والواجهة

تتضمن نتيجة `GameImportService.scan/load` حقل `protection` لكل وحدة حالية.
الخريطة بيانات مشتقة تُنشأ عند القراءة؛ **لا تغير** `source_text`, `old`,
`renpy_identifier`, `source_sha256` أو `protected_tokens` داخل المصدر المحفوظ.
لا يلزم ترحيل SQLite، ولا يعاد إنشاء وحدات المصدر بسبب إضافة هذا الفحص.

تظهر الواجهة عمود **حماية النص** وملخص الجاهز وما يحتاج مراجعة. انقر صفًا لمشاهدة
معاينة النص المحمي أسفل الجدول؛ تظهر رموز الأخطاء مع الملف والسطر في قائمة المشكلات.
جاهزية المصدر للحماية لا تعني ترجمة النص أو اعتماده للتصدير. تبقى الوحدات المرفوضة
مرئية للفحص، ولا تتحول تلقائيًا إلى ترجمات معتمدة.

المعاينة لا ترسل أي شيء إلى مزود. يعرض الأمر التالي الحماية من النتائج المحفوظة:

```powershell
.\.venv\Scripts\rat.exe protect --project "<RAT-project-folder>"
.\.venv\Scripts\rat.exe mock-demo
```

`mock-demo` يجرب mask → Mock echo → validate → restore لعينة مدمجة فقط. لا يترجم
اللعبة ولا يتصل بخدمة. الاستجابة تتضمن `protection_valid` ونتيجة الاستعادة.

## استخدام Core

```python
from rat.protection import MaskingEngine, RestorationEngine

masked = MaskingEngine().mask("Hello [name]! {b}Welcome{/b}.")
if masked.valid:
    package = masked.protected
    # مثال مصطنع: محاكاة تغيير الكلمات مع إبقاء الرموز كما هي؛ لا يوجد API.
    candidate = package.masked_text.replace("Hello", "مرحبًا").replace("Welcome", "أهلًا")
    result = RestorationEngine().restore(package, candidate)
    if result.valid:
        assert result.text == "مرحبًا [name]! {b}أهلًا{/b}."
    else:
        assert result.text is None
        print([issue.code for issue in result.issues])
```

للنصوص المستخرجة استخدم `ProtectionService.prepare_unit(source)` ثم
`restore_unit(source, prepared, candidate)`؛ ولترجمة موجودة غير masked استخدم
`validate_translation(source, translation)`.

## الحدود المقصودة

- يُشترط إغلاق جميع الوسوم الزوجية صراحة حسب متطلبات هذه المرحلة، رغم أن
  [Ren'Py يسمح بترك بعض الوسوم مفتوحة في نهاية النص](https://www.renpy.org/doc/html/text.html#styling-and-text-tags).
  لا يصحح RAT المصدر أو يضيف إغلاقات إليه.
- الوسوم المخصصة غير المعروفة مرفوضة افتراضيًا. يمكن للمطور تعريف أسمائها وأدوارها
  صراحة عبر `TagProtector(custom_paired=(...), custom_self_closing=(...))` وتمرير
  السياسة نفسها إلى الحماية والتحقق. لا تُقرأ أو تُنفذ معالجات اللعبة، ولا توجد
  واجهة إعداد لهذه السياسة حاليًا.
- delimiters الرموز `⟦` و`⟧` محجوزة في النص العادي. ruby غير المهرب `〖...〗`
  والتنسيق الديناميكي المتداخل غير مدعومين ويؤديان إلى رفض واضح؛ `〖〖` يُحفظ كزوج هروب.
- ليس المحلل بديلًا عن جميع قواعد Python أو كل إصدارات Ren'Py؛ وسوم ذات وسائط
  معقدة تتضمن أقواسًا معقوفة داخل التعبير قد تُرفض بصورة محافظة. لا تُفحص قيم
  المتغيرات أو وجود الملفات أو صلاحية اللون والخط في وقت التشغيل.
- حد النص المفكوك 65,536 محرفًا، وعدد tokens في المسح 4,096، وعمق الاستبدال 64.
  يُرفض رد masked أكبر من 524,288 محرفًا قبل تحليل رموزه؛ ويخضع النص المستعاد
  لحد النص نفسه. تظهر diagnostics عند تجاوز الحدود.
- الخرائط مؤقتة في الذاكرة وتتجدد عند فتح التقرير؛ تسلسل JSON متاح، لكن حفظها
  ضمن مهام واستئناف طلبات API يخص المرحلة 3 ولم يُنفذ هنا.
- لا يوجد تصدير بعد. على مسار التصدير المستقبلي فرض نتيجة التحقق وعدم قبول
  فشلها؛ لا تمنح معاينة الحماية حالة `validated` تلقائيًا. مداخل حفظ الترجمات
  منخفضة المستوى ليست بوابة قبول ترجمة أو فحص Ren'Py كاملًا.

المراجع التي استُخدمت للتحقق من القواعد:
[نصوص Ren'Py والاستبدالات والهروب](https://www.renpy.org/doc/html/text.html)،
[الوسوم المخصصة وأدوارها](https://www.renpy.org/doc/html/custom_text_tags.html)،
وملفات `renpy/substitutions.py` و`renpy/text/extras.py` في SDK المحلي **8.5.3**.
لا تُنسخ شيفرة SDK إلى هذا النظام.
