# المرحلة 4 — محرر الترجمة والجودة والتصدير

شرح الاستخدام خطوة بخطوة في [README، المحرر](../README.md#editor)
و[التصدير](../README.md#export). هذه المرحلة لا تضيف تثبيتًا على اللعبة أو RTL أو خطوطًا.

## المحرر والمراجعة

`ReviewService` هو Core المستخدم في واجهة PySide6. يعرض النص الأصلي والترجمة
والشخصية والملف والحالة والمزود وQA وسياق السابق/التالي. الحفظ اليدوي إلى SQLite
مباشر، مع تأخير 500ms في مربع التحرير وحفظ قبل الانتقال والإغلاق.
البحث والتصفية متراكبان؛ التحديد الجماعي يحترم الفرز والنتائج المعروضة.

الحالات: Untranslated، Translated، Needs Review، Approved، Error، Locked.
القفل علم مستقل يحتفظ بالحالة الأساسية؛ يصدّر المعتمد المقفل إن كان سليمًا.
Skip علم استبعاد مستقل، ويُلغى بواسطة Reject أو حفظ مسودة جديدة بعد فتح القفل.
الاعتماد صريح؛ لا يعتمد QA أو المزود ترجمة تلقائيًا. الأخطاء تمنع الاعتماد،
والتحذيرات تسمح بقرار المراجع. Reject يتيح التحرير مع حفظ تاريخ الاعتماد السابق.

Retranslate ينشئ مهام Phase 3 محددة بالـunit_id، من أي ملف مزود محفوظ، مع سياق
الجيران الكامل والحماية والاستعادة والتحقق. ينتج 1–5 بدائل محفوظة منفصلة؛ يتوقف
توزيع الجديد عند Stop وتُحفظ الدفعات الجارية. لا يستبدل النص الحالي أو المعتمد.
تُعطّل TM وإعادة استخدام النصوص لهذا الطلب الصريح، وقد يعيد المزود الصياغة نفسها.
تطبيق البديل عملية يدوية إلى مسودة، مع فحص بصمة المصدر وتعارض التحرير والقفل.
المحاكاة مميزة ولا تُعد ترجمة فعلية؛ لا تُصدّر تلقائيًا دون اعتماد يدوي.

## QA

- أخطاء حاجزة: متغير مفقود أو متغير، وسم مفقود أو متغير، تداخل وسوم مكسور،
  تغيير ترتيب المحميات، أقواس/هروب معطوب، نص فارغ، مصدر غير صالح أو ناتج غير صالح.
- تحذيرات: ترجمة مطابقة للأصل وتحتوي أحرفًا لاتينية، طول مفرط، وتكرار ترجمة
  واحدة لمصادر مختلفة. التحذير ليس حكمًا على جودة الاسم أو المصطلح.
- `QAIssue` يحتوي code وseverity وaffected_text وmessage، وتُعاد النتائج عند
  كل مراجعة وقبل الاعتماد والتصدير. مؤشر تجاوز الواجهة تقريبي من الطول والنسبة؛
  لا يشغّل اللعبة ولا يقيس خطها. لا يوجد تدقيق لغوي أو قياس بصري في هذه المرحلة.

## التصدير

`ExportManager` يكتب داخل `exports/release-<id>/game/tl/arabic` فقط، ثم ينشئ
manifest ببصمات الملفات والمصادر وSDK، وتقريري JSON/HTML، وتعليمات عربية وZIP اختياريًا.
التقرير يشمل العدد المصدّر والمتجاهل والأخطاء ووحداتها والملفات المنشأة. توجد
حالات completed/partial/failed؛ completed لا يعني اكتمال ترجمة كل اللعبة.

يقرأ `TemplateCatalog` قوالب مرتبطة بنصوص المرحلة 1 ومعرّفاتها الفعلية. عند أول
استخدام يتحقق من بصمات المصادر والقوالب، ثم يحفظ لقطة ثابتة في SQLite مرتبطة
بالاستيراد الدقيق؛ بعد ذلك يمكن التصدير دون وجود الأصل. لا توليد معرّفات أو
تخمين خرائط من نص خام. القالب غير الموثق أو الملف المتغير قبل الالتقاط يُرفض.
سلاسل SDK العامة المولدة رسميًا تدعم old/new دون مصدر لعبة مقابل.

الكاتب يحافظ على ترتيب القوالب والكتل والتعليقات والـIDs وأسماء المتحدثين وسمات
الحوار وvoice/nvl الساكنة المدعومة، ويستبدل النص المستهدف فقط. لا ينسخ Python
أو تعليمات غير مدعومة. كتلة حوار متعددة السطور تتطلب اختيار جميع وحداتها السليمة؛
لا يُصدر نصف كتلة. تُرفض مفاتيح متعارضة ومعرّفات مكررة وتصادمات مسارات Windows.

**سلاسل `old/new` لها قواعد Python literals في SDK، بينما الحوار يستخدم قواعد
Ren'Py**. لذلك الكاتب يستخدم ترميزًا مستقلًا لكل منهما؛ المحلل يقرأ literal
ثابتًا بـast.literal_eval فقط في old/new، ولا ينفذ تعبيرات اللعبة. الحوار يحفظ
الفراغات والهروب؛ old والمصدر يظلان كما وردا. يُعاد تحليل كل ملف ناتج ومطابقته
قبل خروجه من staging. اختبار SDK الحقيقي يتحقق من اختلاف القاعدتين فعليًا.

لا ينشئ التصدير لغة ضمن قائمة اللعبة، ولا يقيس مظهر العربية، ولا يضيف خطًا أو
حالة validated عامة. اللغات المخصصة وPython وruby والتراكيب التي رفضتها المراحل
السابقة تظل محجوبة؛ لا نخفف الحماية لتصديرها.

## النسخ الاحتياطي والأوامر

`BackupManager` ينشئ نسخة متسقة عبر SQLite backup مع YAML والجرد وmanifest SHA256
داخل `backups/backup-...`، ويوفر verify. النسخة لعمل RAT وليست نسخة من اللعبة،
ولا تحتوي مفاتيح مخزن النظام. استعادة/تثبيت فوق أصول اللعبة خارج النطاق.

```powershell
.\.venv\Scripts\rat.exe qa --project "<project>"
.\.venv\Scripts\rat.exe export --project "<project>"
# للسماح بالمسودات السليمة: --include-unapproved، ولإلغاء ZIP: --no-zip
.\.venv\Scripts\rat.exe backup --project "<project>"
```

نتائج التحقق والملفات في [تقرير المرحلة 4](phase4-verification.md).
