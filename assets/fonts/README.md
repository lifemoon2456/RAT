# خطوط RAT

الخط الافتراضي Amiri Regular مرخص بـSIL OFL 1.1، وملفه ونص رخصته ضمن
`src/rat/resources/fonts/amiri` كي يشملا wheel وEXE أيضًا.
المصدر: https://github.com/google/fonts/tree/main/ofl/amiri
لم يُعدّل ملف الخط. الخطوط التي يختارها المستخدم تحتاج نص رخصة وحق إعادة توزيع
قبل نسخها إلى حزمة اللعبة؛ فحص المحارف لا يمنح ترخيصًا.
